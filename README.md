# Familien- und Erwachsenenbildung unter Druck

Interaktive Präsentation mit zehn Thesen zu aktuellen Veränderungen der Familien- und Erwachsenenbildung. Die Anwendung verbindet Thesen mit empirischen Befunden, rechtlichen Entwicklungen und weiterführenden Quellen.

**Autorin:** Elisabeth Vanderheiden  
**Version:** 1.0 (2026)  
**Format:** Interaktive HTML-Anwendung

## Nutzung

Die Anwendung kann direkt über GitHub Pages aufgerufen werden:

https://research2026-collab.github.io/EB-unter-druck/

## Zitation

Die bibliografischen Metadaten sind in `CITATION.cff` hinterlegt. Nach der Archivierung eines Releases bei Zenodo kann hier zusätzlich der DOI und die vollständige Zitierempfehlung ergänzt werden.
